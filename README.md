# RP Companion

Локальная панель для планирования игровой сессии: тёмный интерфейс, чек-лист задач, таймер, заметки и простая статистика.

Проект сделан самостоятельно по мотивам идеи модульной панели из [исходного проекта на Codeberg](https://codeberg.org/dornode/bot). Он не копирует его исходный код и не управляет игрой, не нажимает клавиши автоматически и не обходит AFK-ограничения.

## Запуск на Windows

1. Установи Python 3.10 или новее.
2. Открой PowerShell в папке проекта.
3. Выполни:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

4. Открой в браузере `http://127.0.0.1:5000`.

Можно запустить двойным кликом по `run.bat`.

Данные сохраняются в локальный файл `data.json`, который исключён из Git. Секреты и личные данные в проект не входят.

## Структура

- `app.py` — небольшой Flask-сервер и API;
- `templates/index.html` — интерфейс приложения;
- `static/style.css` — тёмная адаптивная тема;
- `static/app.js` — таймер, задачи и сохранение заметок.
